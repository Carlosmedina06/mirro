## Duplicación

Se aplican la próxima vez que empieces a duplicar un dispositivo.

| Opción | Qué hace |
| --- | --- |
| **Apagar pantalla del teléfono** | La pantalla del teléfono se apaga mientras lo usas desde la Mac. Ahorra batería. |
| **Mantener despierto** | El teléfono no se bloquea mientras está conectado. |
| **Sin audio** | No transmite el sonido del teléfono a la Mac. El audio requiere Android 11 o posterior. |
| **Ventana siempre encima** | La ventana del teléfono queda por encima de las demás. |
| **Mostrar toques** | Muestra en el teléfono un punto donde haces clic. Útil para grabar demos. |
| **Resolución máxima** | Limita la resolución del video (1024, 1600 o 1920 px). Útil por WiFi o en Macs antiguas. |

## General

| Opción | Qué hace |
| --- | --- |
| **Abrir al iniciar sesión** | Mirro se abre sola al encender la Mac. |
| **Mostrar esta ventana al abrir Mirro** | Si lo desactivas, Mirro arranca solo en la barra de estado. |
| **Repetir configuración inicial** | Vuelve a mostrar el onboarding. |
